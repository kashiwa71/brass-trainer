# Brass Trainer（チューバ練習アプリ）

吹奏楽でチューバを吹く人向けの、ブラウザーで動く練習アプリです。スマホやパソコンのマイクで演奏を解析し、苦手なところを数字で見えるようにします。

## 練習モード

プロ奏者・指導者が公開しているアドバイス（アーノルド・ジェイコブス、東京佼成ウインドオーケストラの小倉貞行氏、David Dunham、Norlan Bewley、河野一之氏ほか）をもとに構成しています。練習中は状況に合ったアドバイスが表示され、「出典を見る」から元の記事に飛べます。

| モード | 目的 | 判定 |
| --- | --- | --- |
| 耳トレ（聴いて歌う） | 音を取る力の土台。基準音を聴いて声で同じ音名を出す（高さは自由） | 針が高い・低いを大きく示し、一定時間収まれば合格。段階: 聴いてすぐ → 別の音を聴いてから → 思い出して |
| ドローン合わせ | 鳴り続ける基準音に合わせて伸ばし、うなりが消える所を覚える | ±10 ¢ に入っていた時間の割合、揺れ、ずれの癖 |
| 音当て（歌ってから吹く） | H など特定の音を、声で当ててから冷えた状態で一発で吹く | 発音直後 50〜300 ms のピッチが狙った倍音に乗ったか。外したときに乗った音も記録。5 度以内のランダム跳躍モードあり |
| 出だし | 音の出だしをまっすぐ・きれいに始める | 安定までの時間、しゃくり上げ、別の倍音への引っかかり、音量の立ち上がりを 100 点満点で採点 |
| リップスラー | 同じ運指で倍音を移動する（オクターブ跳躍を含む） | 途中の倍音への引っかかり、届かなかった音、移行中の不明瞭な時間。連続成功でテンポ自動上昇 |
| タンギング（テンポの階段） | 決まった数の音を均等にタンギングする | 音数、間隔の均等さ、拍からのずれで合否。合格でテンポ上昇、不合格で下降 |

音名はドイツ音名（B = シ♭、H = シ）で表示します。既定は B♭ チューバ、基準ピッチ A = 442 Hz で、設定画面で変えられます。

## 画面の考え方（譜面台に置いて使う）

- スマホを譜面台に置き、50〜70 cm 離れて見る前提で、案内文・音名・判定・針を大きく表示します。文字の大きさは設定で「標準／大／特大」を選べます。
- 開始・停止は画面下に固定した大きなボタンです。練習中は説明・設定・成績表を隠し、今やることだけを出します。
- 練習中は画面が消灯しないようにします（Screen Wake Lock 対応ブラウザー）。
- 横向きに置くと、出題と結果を左右に並べます。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー（LAN 内のスマホからも開けるよう --host 付き）
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果を確認
npm test         # 単体テスト
```

マイクを使うため、`localhost` 以外では HTTPS で開く必要があります。`dist/` を GitHub Pages などの静的ホスティングに置けば、スマホのホーム画面に追加してオフラインでも使えます（PWA）。

## 仕組み

- マイク入力を AudioWorklet で受け取り、Web Worker で約 12 kHz に間引いてから YIN 法でピッチを検出します（チューバの低音 約 40 Hz まで対応）。
- 発音は音量の立ち上がりで検出します。開始時に 1 秒間の暗騒音を測り、閾値を決めます。
- 判定ロジックは DOM に依存しない純粋関数で、`tests/` に単体テストがあります。
- 練習履歴はブラウザーの localStorage に保存され、設定画面から JSON で書き出せます。

## 練習モードの追加

`src/trainers/` にモジュールを 1 つ足して `src/trainers/index.ts` に登録するだけです。詳しくは [docs/ADDING_A_TRAINER.md](docs/ADDING_A_TRAINER.md) を参照してください。

## アドバイスの追加

`src/content/advice.ts` に項目を足します。必ず出典 URL を付け、`triggers` に「どの出来事のときに出すか」を書きます。練習画面の「次はこうする」と「アドバイス集」に自動で反映されます。

## 構成

```
src/
  core/
    notes.ts          音名・周波数
    tuba.ts           倍音列・運指モデル
    analysis/         YIN、発音検出、音の区切り
    audio/            マイク入力、解析ワーカー、基準音、メトロノーム
    trainer.ts        トレーナーの共通インターフェースと登録簿
    history.ts        練習履歴
    settings.ts       設定の保存
    wakelock.ts       画面の消灯防止
  content/advice.ts   プロ奏者・指導者のアドバイス集（出典リンク付き）
  trainers/           練習モード（1 フォルダー = 1 モード）
  ui/                 画面の骨組みと部品
public/               AudioWorklet、PWA 用ファイル
tests/                単体テスト
```

## 楽器なしで動作確認する（e2e）

合成したチューバ音を Chromium の疑似マイクとして流し、各モードの判定が動くことを確かめられます。

```bash
python3 e2e/make-wavs.py                 # 合成音を生成
npm run build && npx vite preview --port 4173 &
npm run e2e -- note-attack               # note-attack | note-attack-sing | attack-quality | lip-slur | tonguing | ear-training | drone
```

`playwright-core` が Chromium を見つけられない場合は `CHROME=/path/to/chrome` を指定してください。

## 公開（GitHub Pages）

1. リポジトリの Settings → Pages で Source を「GitHub Actions」にする
2. 既定ブランチ（main）にマージするか、Actions の「CI and Pages」を手動実行する
3. 表示された URL をスマホで開き、「ホーム画面に追加」するとアプリとして使える
